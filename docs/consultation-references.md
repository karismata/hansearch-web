# 월별 상담 이력: 미검증 참고

맥미니에서 다음 폴더를 사용합니다. 별도 패키지나 새 API 키는 필요 없습니다.

```text
/Users/elt/Documents/Hansearch AI/상담이력/
└── 2026/
    ├── 2026-10.xlsx
    └── 2026-11.xlsx
```

월별 파일을 따로 보관하고 같은 달 재추출은 같은 이름으로 교체합니다. 파일은 저장을 마친 뒤 옮겨 주세요. `YYYY/YYYY-MM.xlsx`만 읽으며 엑셀 임시 파일은 무시합니다. 다른 폴더를 쓰려면 기존 `.env`에 `CONSULTATION_DIR`을 지정할 수 있습니다.

서버 시작 및 매 300초 동기화 때 추가·교체·삭제를 반영합니다. 변경 없는 파일은 다시 해석하지 않습니다. 읽기에 실패하거나 삭제한 파일의 이전 기록은 참고에서 제거하며, 다른 정상 파일은 계속 사용합니다. 이미 화면에 표시된 답변은 새로 검색해야 갱신됩니다.

`상담메모`, `처리내용` 헤더를 처음 10행에서 찾습니다(기존 추출물은 2행). 두 필드가 있는 행 중 짧은 접수·완료 멘트만 있는 행을 제외합니다. 메모 없는 처리내용 행은 앞 상담과 임의로 연결하지 않습니다. 수식은 계산하거나 캐시를 읽지 않습니다. 원본은 수정하지 않습니다. 파일당 압축 20MB/해제 80MB, 사용 가능 기록 25,000건 이내입니다.

AI 검색 시 기기·증상이 맞는 관련 기록 최대 3건을 찾습니다. 추가 임베딩 생성 없이 메모의 검색어와 기기·증상 조건으로 선별하므로 표현이 크게 다르면 누락될 수 있습니다. 정식 자료 답변과 별도로 **미검증 상담 참고**를 표시하고, 펼치면 파일·시트·행 번호와 짧은 문의/처리 기록을 볼 수 있습니다. 한 번의 기존 로컬 답변 생성 요청에 참고 요약을 함께 맡기며, 정식 자료 충족 여부 판단과 인터넷 검색 여부는 상담 이력으로 바꾸지 않습니다. 처리완료는 해결 입증으로 간주하지 않습니다.

원본 엑셀은 맥에만 보관하고 메모리에서 읽습니다. Supabase 정식 자료, 일반 검색 목록, GitHub, 웹 배포물에 등록하지 않습니다. 처리그룹·담당자 열은 사용하지 않고 자유서술의 전화번호·이메일·URL·일부 식별정보를 마스킹합니다. 자유서술의 모든 개인정보를 자동으로 식별할 수는 없으므로, 민감한 정보는 원본 반입 전에 제거해 주세요. 선별한 마스킹 발췌와 요약은 로그인한 검색 사용자에게 전달되며 기존 Cloudflare 중계 작업에 잠시 보관됩니다. 엑셀 본문·발췌를 Tavily 검색어에 덧붙이지 않습니다.

‘답변 수정·저장’에는 상담 참고의 미검증 표시와 출처도 포함됩니다. 현장에서 확인한 뒤 직접 내용을 수정해서 저장하세요. 자동으로 검증 자료로 승격하지 않습니다.

확인은 서버를 켠 채 다른 터미널에서도 가능합니다(파일 내용은 출력하지 않음).

```bash
cd "/Users/elt/Documents/Hansearch AI/hansearch-web-codex-local-ai-sync/local-ai"
python3 server.py --check-consultations
```

서버 로그의 `[consultation]` 및 `/health`의 `consultations`에 파일 수, 사용 가능 기록 수, 제외 수, 읽기 실패 수가 표시됩니다. 코드 업데이트는 기존 `update-local-ai.command`를 사용합니다. 기존 `.env`를 예제 파일로 덮어쓰지 마세요.
